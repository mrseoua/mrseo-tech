# MrSeo.tech — единый стандарт страниц / v2

Зафиксировано 24.11.2026 на основе принятой страницы /seo/, пяти рекламных страниц и текущей задачи владельца: закончить сайт, а не бесконечно менять дизайн.

## Обязательный стандарт

- Дизайн: светлый тёплый #f7f3ed, графит #252c26, акцент --mrseo-brand-red (#A84432), читаемый текст #57554b, тонкие границы #ded3c7. Контентная ширина до 1350px; крупный H1 44–76px desktop / 36–52px mobile, H2 35–64px / 32–45px, основной текст 17–21px, ссылки и CTA контрастные. Проверять реальные размеры, а не просто объявление CSS.
- Первый экран: название услуги, одна ясная цель/боль, действующий H1 и проверенный SEO lead, контакт и ссылка на следующий блок; один уникальный визуальный сюжет по услуге.
- Проблема → конкретное решение: 3 узнаваемые ситуации, рядом то, что специалист проверяет или меняет. Никакой воды, одинаковых абзацев на разных страницах или гарантированных показателей.
- Что делаем и что получает бизнес: сохранённый перечень работ, контроль результата, чёткий deliverable. Аудит не равен внедрению; различать отчёт, настройку, ведение, готовый продукт. На хабах — реальный каталог всех соответствующих услуг (даже не в шапке).
- Условия: согласуем состав, бюджет, сроки и оплату до начала; только подтверждённые цены, без придуманных пакетов или цифр. Не дублировать формулировки в каждом блоке.
- Доверие: реальный опыт, команда, фактические инструменты, конфиденциальность. **Публичных кейсов нет. Не предлагать, не выдумывать, не создавать блок кейсов, логотипы/отзывы/результаты без подтверждения.**
- FAQ, контекстные внутренние ссылки, один финальный контактный CTA. Не терять существующие анкоры, H1, title, description, canonical, hreflang, sitemap, Serpstat semantics, рабочие формы и 20 локалей. Noindex/nofollow до отдельного разрешения. Главная (3D Earth и утверждённые блоки) и меню зафиксированы; не менять в рамках этой нормализации.
- Движение: различимые сюжеты, без рывков/тяжёлых фильтров, отключение вне экрана и reduced-motion. Нет постоянно видимых pause-кнопок; доступность с клавиатуры сохраняется. Не добавлять анимацию ради анимации.

## Последовательность работы и критерий готовности

Сначала UA, пакетами по кластеру, без повторной переработки принятой композиции. Затем соответствующие 19 языков: переиспользуем общий дизайн и локальные тексты, не изобретаем новые макеты и не создаём отсутствующие языковые маршруты. Хорошоп только UA/RU.

1. Проверить фактический URL, активный шаблон и содержание, составить diff по стандарту. Не считать смену CSS полным редизайном.
2. Изменить только необходимые компоненты. Не менять утверждённые SEO-тексты без причины; сохранять существующие иллюстрации, если они подходят. Подключать общий слой только явно выбранным страницам; не ломать другие шаблоны.
3. PHP/JS/SEO и route regression, 1440/390/360px: screenshot hero/problem/services/CTA, читаемость, отсутствие наложений/overflow, работа меню/форм, движение и reduced motion. Проверить deploy отдельно. Если визуальный просмотр недоступен, статус **технически готово, визуальная приёмка не подтверждена**. Не объявлять страницу завершённой по merge.
4. Отметить в реестре конкретный PR, проверенный production commit и результат визуального QA. Не повторять уже выполненную работу. Постоянное разрешение владельца на публикацию согласованных изменений сохраняется; индексация — отдельно.

## Эталон подкатегорий: /local-seo/ (24.11.2026)
Владелец поручил сделать эту страницу эталоном маркетинговой структуры. Для узкой услуги — один выразительный интерактивный hero, три компактные иллюстрации без движения в рядах проблема→решение, три группы конкретных работ, результат с измеримыми показателями (без вымышленных цифр), условия рядом с результатом, FAQ, один финальный CTA. Не дублировать технические сцены внизу ради красоты; убрать повторяющиеся абзацы. Не добавлять цены, обещания бесплатного аудита, результаты и кейсы без подтверждения. После визуальной приёмки использовать структуру для других услуг, не копируя локальные тексты или графику. H1, Serpstat lead, metadata, original hero и рабочие URL сохранены. Новый шаблон подключён только для UA local-seo. Остальные страницы не изменены.
